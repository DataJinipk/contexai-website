What you will be able to do

On successful completion, you will be able to:

  • Explain why a value's type determines which operations Python allows on it.
  • Implement a function that converts, computes and formats values.
  • Trace which branch of an if, elif and else chain runs for a given value.
  • Implement a function that classifies a value using ordered conditions and correct boundaries.
  • Use a loop to accumulate a total over a list of records.
  • Use a dictionary to combine values that share a key.
  • Interpret a Python traceback to locate the line and the cause of an error.
  • Detect and correct defects in AI-generated code using failing tests.
  • Trace a function call by matching each argument to its parameter, including default and keyword arguments.
  • Predict which names a function can read and which it changes, telling local names from global ones.
  • Implement a task as small functions that each do one job, reusing one function instead of copying its code.
  • Read a text file line by line inside a with block, and write results to a new file in the right mode.
  • Clean and split each line of text with strip, split and splitlines, skipping blank lines and counting malformed ones.
  • Implement file processing as functions that take text and return text, keeping the file reading and writing at the edges.

How it works

Every module is taught aloud, one line at a time, with a pause after each line so it lands before the next one arrives — and you can go back, skip or replay at any point. Each module ends with a coding exercise graded by automated tests: you pass when your code does.

On completion you receive a ContexAi Academy Certificate of Completion. It records what you can demonstrably do; it is not an accredited qualification.
