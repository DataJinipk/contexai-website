Working with Data: Cleaning, Encoding and Leakage

The work that consumes most of a real project and appears in almost no course: missing values, encoding, imbalance and provenance. CS2023 added this to the core precisely because its absence was doing damage.

How it works

Every module is taught aloud, one line at a time, with a pause after each line so it lands before the next one arrives — and you can go back, skip or replay at any point. Each module ends with a coding exercise graded by automated tests: you pass when your code passes its tests.

On completion you receive a ContexAi Academy Certificate of Completion. It records what you can demonstrably do; it is not an accredited qualification.
